01 · 问题背景

把合法构型计数写成一个可审计的张量网络

N 皇后问题要求在 N×N 棋盘放置 N 个皇后，使任意两个皇后不共享行、列或两族对角线。 Q(N) 是全部合法构型的精确数目。这里研究的是精确组合计数，而不是把一个浮点近似四舍五入成整数。

组合学问题

每行恰有一个皇后，且列与两族对角线上至多一个。直接枚举有阶乘级候选空间；位棋盘 DFS 是经典高性能路线。

统计物理表示

把皇后占据视作晶格气体，把排斥规则编码进虚指标传播。网络的全收缩等于零温基态简并度 Q(N)。

可迁移方法

同一“局域规则 → 稀疏张量 → 构型计数”框架可用于 ice rule、Rydberg blockade、硬方格等受约束模型。

Sec. VI 的精确 PEPS

Liu、Liao、Wang 将 N 皇后写成一个有限尺寸张量网络。每个格点有一个物理占据指标 α∈{0,1}，以及列、行、右下对角线、左下对角线四个有向约束通道；每个通道各有一入一出两个 dimension-2 虚指标。因此局域张量 B 是 rank-9，而求和物理指标后的计数张量 C=ΣαB 是 rank-8。完整网络与全构型积态的内积给出：

Q(N) = ⟨Ψ | (|0⟩ + |1⟩)⊗N² = Contract(C⊗N², v0, v1, v2)

这不是把 N 皇后递推“改名”为 PEPS：本项目显式构造 B、显式得到 C，并从 C 的条目机械生成所有快路径。 这种来源链条是后续“为何热循环像 DFS”仍能被称为 proved-equivalent optimized contraction 的依据。

复杂度表述：本报告不把标准 Q(N) 序列草率称为“NP 问题”。它是一个精确计数任务；相关的广义放置/补全决策问题可以具有 NP 完全性，但本研究关心的是有限 N 的 #solutions 与张量收缩复杂度。

为什么这一框架具有物理意义

自旋冰中，two-in/two-out 的 ice rule 本身就是局域稀疏约束；收缩对应合法冰构型数、残余熵与受挫体系的基态简并。 里德堡阻塞中，阻塞图上的激发构型等价于独立集；合法基矢数就是受阻塞 Hilbert 空间维数。 这些系统比 N 皇后的长程行列/对角线传播更局域，但共享“巨大零结构与强约束”的算法特征。

02 · 研究结论

精确稀疏 PEPS 的极限优化，揭示了张量收缩与状态搜索的同源性

当局域张量主要承载确定性的约束传播，而非一般稠密振幅时，“收缩”真正做的事情是维护仍可能延拓为合法全局构型的边界状态。 机械消去零元、编译局域关系并避免晚层中间张量物化后，这一过程会自然形成位掩码状态更新与深度优先 continuation traversal。

我们真正证明了什么

  • 显式 17-entry B/C 与边界条件构成真实 Sec. VI 网络。
  • 逐行 C-transfer 可被 fail-closed 地编译成列与对角线 bitmask 自动机。
  • 后期递归仍逐步应用该 C-derived relation；它不调用 DFS 模块或已知计数表。
  • 在有限 N 与一个冻结实现对照中，优化 PEPS 可以达到并略快于仓库 DFS comparator。

我们没有证明什么

  • 没有证明 PEPS 具有更低的渐近指数。
  • 没有证明它胜过所有同等微优化的 N 皇后 DFS。
  • 没有复现 Q(27)，也没有得到 Q(28)。
  • 没有证明这些结论可无条件外推到一般复数、稠密、纠缠 PEPS。

三条最重要的实证结论

结论 A
支持度比拓扑更重要。 Generic TreeSA、dense width 与几何 cut 不能预测实际非零中间张量；最优路径必须计入 tensor values、actual sparse support、物化字节和已校准 kernel 成本。
结论 B
最大转折来自改变中间表示。 E38/E40 不再物化最宽晚层 frontier，而改为“小 prefix + C-derived recursive tail”。这比继续优化哈希、排序或缓存更接近根因。
结论 C
低秩与截断不能只看形式。 边界具有低秩诊断信号，不等于能廉价构造该低秩表示；常规 SVD 截断在 N=14、χ=128 仍丢失 99.9963% 的计数。
最稳健的表述：项目成功完成了一项“张量网络如何编译成组合搜索”的方法研究，并把朴素显式-C 收缩从不可扩展的巨型 frontier 推进到低内存、可验证、可运行至 N=22 的精确实现；它没有推进 N 皇后世界纪录。
03 · 张量网络保真与精确性

从 17 个局域非零元到位掩码热循环：每一步都必须可回放

局域张量的 17 个条目

空格点 α=0：16 项

四个约束通道彼此独立地传递 0 或 1；每个通道出信号等于入信号，因此共有 24=16 个非零条目。

占据格点 α=1：1 项

四个通道的入信号全部为 0、出信号全部为 1，表示当前格点第一次在每条约束线上发出“已有皇后”信号。

B 因而恰有 17 个非零元；对 α 求和得到 C 后，16 个空传播项与 1 个占据项仍不重合，所以 C 也恰有 17 个非零元。

边界向量

边界向量作用本实现
约束线起点v0=(1,0)进入棋盘前尚未出现皇后显式测试
行与列终点v1=(0,1)强制恰好一个皇后显式测试
两族对角线终点v2=(1,1)允许 0 或 1 个皇后，即至多一个显式测试

本实现采用文档化的 row-major 对角线方向；若翻转某一对角通道，其 v0/v2 端点也同时翻转，物理线约束不变。

逐行等价命题

命题（简述）：在上述 B/C 与 v0/v1/v2 下，完成一行的物理指标收缩后，可达边界态与三个冲突集合 (columns, diagDR, diagDL) 一一对应。当前行可占据位置恰为 available = boardMask & !(columns | diagDR | diagDL)；选定位置后的三个集合更新，正是 occupied C 条目沿列与两族对角虚键传播的机械结果。

这解释了最终热循环为何与 bitboard DFS 相似。相似性来自同一约束自动机，而不是偷换模型。仓库中的证明说明、逐 parent replay 和测试把下面这条链闭合：

显式 B → 物理收缩得到 C → fail-closed row compiler → reachable-parent replay → certified tail plan → 优化热循环

精确算术

所有正式计数使用 checked 整数或有限域/CRT。N≤20 的非负部分计数由 N! 上界认证可走 scalar-u64；更宽 N 使用多个 32-bit primes， 并在模数乘积超过可证明计数上界后做唯一 CRT 重构。浮点、SVD 阈值与整数 rounding 均不进入正式 Q(N)。

04 · 各优化方向分类与总结

60 个方向不是“堆技巧”，而是四次瓶颈认知转变

每个方向在独立 worktree/branch 中预注册假设、正确性义务与 keep/kill gate；每五个方向强制复盘。 KEEP 表示机制在指定门槛下成立，REJECT 也保留数据和失败原因。不能把跨硬件、跨 revision 的最佳数字拼成虚假的总 speedup。

阶段 A · E1–E10

解释器与容器

索引 17-entry C、紧凑 key、buffer reuse、sort-reduce、并行 slicing。N=14 串行链从 25.19 s 降至 3.09 s，但 support 未变。

阶段 B · E11–E35

结构压缩探索

vertical D4 有效；DD/ZDD、future quotient、低秩、generic path 等多数发现结构却无法在物化前利用。

阶段 C · E24–E47

表示与结合顺序

紧凑 record、bounded flush、窄算术；E38/E40 以 recursive tail 删除晚层 materialization；E42/E47 编译 last-k supernode。

阶段 D · E48–E60

热核边际耗尽

stack、AVX2、cache、I-cache、ILP、更多 unroll 均未过 gate。99.98% 热点是必要的低复用 C-state expansion。

成功与失败的分界

成功模式

  • 在 apply 过程中机械 partial evaluation，而非事后压缩。
  • 减少真实 record 数、bytes 与物化层数。
  • 只使用当前 cut 上便宜、可证明的对称性。
  • 用 exact certificate 选择窄算术与 terminal supernode。
  • 把并行粒度与内存组织共同设计。

失败模式

  • 仅优化 dense proxy、理论 width 或抽象 contraction tree。
  • 先物化完整对象，再做 DD、rank、quotient 或 SVD。
  • 在几乎不汇合的状态空间上强加 memoization/cache。
  • 假设 full D4 必然带来 8×，忽略 canonicalization 成本。
  • 不减少 C nodes，只手写 stack/SIMD/ILP。

07 · APX1 近似诊断

有限 χ 看似控制了规模，却几乎丢掉了全部计数

08 · 对强约束物理 PEPS 的启示

这项研究的价值在方法论，而不在刷新 N 皇后纪录

N 皇后张量是非负、布尔虚键、极稀疏的经典约束网络；一般强关联 PEPS 可能是复数、稠密、含符号抵消并需要近似环境。 因此下面是可检验的迁移假设，而不是未经验证的普适定理。

1 · Support-aware contraction

收缩代价不应只由 cut 上有多少虚键决定，而应由存活非零 sector、真实物化字节和压缩后的 continuation 决定。强约束体系需要 data-dependent path cost。

2 · 局域张量机械编译

当局域张量本质是 ice rule、Gauss law、blockade 或 dimer constraint 时，不应一律当成稠密数组。JIT/算子生成可把它编译成 bitwise 或 sparse automaton。

3 · 对称性有隐性簿记成本

block-sparse 与点群对称不是无条件收益。若 canonicalization、hash 与 sector 管理作用在每个 node，而维度只小幅下降，它会成为负优化。

4 · 平坦连续数据优于复杂图结构

在 exact contraction 中，指针跳转与哈希常比算术更贵。packed key-value、顺序生成与 sort-reduce 往往比通用 DD/图容器更适合吞吐。

5 · 警惕 algebraic fill-in

“事后低秩”不等于“可廉价生成”。PLUQ、QR/SVD 若先形成大对象或破坏计算基稀疏性，fill-in 会抵消理论 rank 优势；压缩必须进入 apply 过程。

6 · BFS→DFS 的混合环境

边界还小时合并相同 sector；环境即将爆炸时 slicing，并把剩余子网流式收缩成独立标量任务。核心是避免巨型中间环境，而非只加速其分解。

两个直接物理映射

自旋冰 / ice rule

局域 two-in/two-out 张量收缩给出 ice manifold 的构型数与残余熵；三维受挫体系已有 PEPS/张量网络计算残余熵和 Coulomb-phase 关联的研究。

Rydberg blockade / 独立集

阻塞半径内不能同时激发，等价于图独立集约束。全合法构型计数给出 blockade Hilbert space 维数；加 fugacity 后得到 hard-square/independent-set 配分函数。

下一代工具应优化什么：不是“裸 contraction tree”，而是 contraction strategy + compression strategy + target observable sensitivity。 理想的自动化工具应能从局域张量值推导宏算子，在线估计 actual support，并在物化、合并、切片和递归之间动态选择。
