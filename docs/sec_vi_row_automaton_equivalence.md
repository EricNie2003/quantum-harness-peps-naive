# Sec. VI row contraction and the three-mask automaton

## Scope

This note states the mathematical equivalence used by the optimized N-Queens
PEPS implementation. It distinguishes the tensor network, a row transfer
relation, a contraction schedule, and a conventional DFS implementation. The
equivalence establishes tensor-network fidelity; it does not establish that the
tensor formulation has a better asymptotic complexity than DFS.

All statements are over an exact commutative semiring. The production instances
use checked nonnegative integers or finite fields followed by certified CRT.
Floating-point truncation is outside this theorem.

## Local tensor and boundaries

At site `(r,c)`, let `alpha in {0,1}` be physical occupation and let each of the
four directed channels—row, column, down-right diagonal, and down-left
diagonal—have an incoming and outgoing bit.

The rank-9 tensor `B` has exactly these nonzero entries:

1. If `alpha=0`, every channel independently passes its bit unchanged. There
   are `2^4=16` such entries, each with coefficient one.
2. If `alpha=1`, all four incoming bits are zero and all four outgoing bits are
   one. There is one such entry, with coefficient one.

The rank-8 counting tensor is `C = sum_alpha B`. The empty and occupied tuples
do not collide, so `C` also has exactly 17 nonzero entries.

Every directed line starts with `v0=(1,0)`. Rows and columns end with
`v1=(0,1)`, selecting signal one. Both diagonal families end with
`v2=(1,1)`, accepting signal zero or one. The implementation orients the two
diagonal channels so that, between consecutive rows,

```text
diag_dr' = ((diag_dr | selected) << 1) & board_mask
diag_dl' =  (diag_dl | selected) >> 1
```

The opposite orientation is equivalent if its start and end boundaries are
reversed together.

## Definitions

For a board of width `N`, encode the incoming column and diagonal virtual bits
at the top of a row by three N-bit masks

```text
s = (columns, diag_dr, diag_dl).
```

Let `R_N(s,t)` be the exact tensor obtained by contracting all N local `C`
tensors in that row, every horizontal bond, the horizontal `v0` start, and the
horizontal `v1` end, while leaving the three incoming and three outgoing mask
families open. Off-board diagonal signals are contracted with the corresponding
`v0` or `v2` endpoint.

Define

```text
available(s) = board_mask & !(columns | diag_dr | diag_dl).
```

For a one-bit mask `p`, define

```text
F(s,p) = (
    columns | p,
    ((diag_dr | p) << 1) & board_mask,
    (diag_dl | p) >> 1
).
```

## Lemma 1: row contraction selects exactly one occupied site

For any fixed incoming boundary `s`, every nonzero term of the horizontal row
contraction contains exactly one occupied local entry.

### Proof

The horizontal signal enters as zero because of `v0`. If every site takes an
empty entry, the signal remains zero and the final `v1` annihilates the term.
Therefore a nonzero term contains an occupied entry.

At the first occupied entry, the horizontal incoming bit must be zero and the
outgoing bit becomes one. Every later empty entry passes that one unchanged. A
second occupied entry would require horizontal incoming zero, so its local
coefficient is zero. Thus there is exactly one occupied site. Conversely, a row
with one locally admissible occupied entry and empty pass-through entries
elsewhere ends with horizontal signal one and is selected by `v1`. QED.

## Lemma 2: the occupied position is the zero set of the three masks

An occupied entry at column `p` is nonzero exactly when bit `p` is zero in all
of `columns`, `diag_dr`, and `diag_dl`.

### Proof

The occupied entry of `C` requires incoming zero on all four channels. Lemma 1
already supplies horizontal incoming zero at the unique occupied site. The
remaining three incoming values are precisely the three bits represented by
the masks. All empty sites pass their incoming bits unchanged. Therefore the
legal one-bit choices are exactly the bits of `available(s)`. QED.

## Theorem: exact row-transfer isomorphism

For every incoming mask triple `s`,

```text
R_N(s,t) = number of one-bit p in available(s) such that t = F(s,p).
```

For the Sec. VI tensor and labeled board columns, distinct legal `p` give the
corresponding exact row successors with unit local weight. Equivalently, the row
tensor is the sparse transition relation generated by iterating the set bits of
`available(s)` and applying `F`.

### Proof

By Lemma 1, every nonzero row term has a unique occupied column `p`. By Lemma 2,
that column is a set bit of `available(s)`. The occupied local tensor changes
the three outgoing constraint signals at `p` from zero to one; all other local
tensors pass their signals. Moving to the next row leaves the column bit in
place and translates the two labeled diagonal families by the documented
shifts, with off-board ends contracted by `v0`/`v2`. This is exactly `F(s,p)`.

Conversely, each set bit `p` of `available(s)` defines one nonzero assignment:
choose the occupied C entry at `p` and the uniquely matching pass-through entry
at every other site. Every coefficient is one. These constructions are inverse,
which proves the claimed sparse relation. QED.

## Corollary 1: full contraction and bitmask search are path-isomorphic

Start with `(0,0,0)` at the top boundary and apply the row relation N times.
The nonzero paths are in weight-preserving bijection with placements containing
one queen in every row and no repeated column or diagonal. The final column
`v1` boundaries select masks in which every column signal is one; final diagonal
`v2` boundaries accept either signal. Hence the complete contraction equals
`Q(N)`.

A conventional row-wise bitmask DFS enumerates the same path set when it uses
`available` and `F`. This is an isomorphism of the mathematical transition
systems, not an identity of implementations: the independent comparator need
not construct `B`, `C`, or a compiler certificate, and it remains classified as
DFS.

## Corollary 2: hybrid prefix/tail and last-k execution are contractions

The full network is a finite sum of products. Partitioning the row-transfer
composition after depth `d`, evaluating each remaining subtree recursively, or
contracting the last `k` row tensors into a certified terminal function changes
only parenthesization and evaluation schedule. Associativity and distributivity
give the same exact result.

Therefore the optimized prefix/tail and last-k implementations are legitimate
contraction-tree reassociations if, and only if:

1. their row relation was mechanically compiled from the explicit `C`;
2. every task covers a disjoint part of the boundary sum and all tasks are
   reduced exactly;
3. the terminal function is checked against generic explicit-C replay;
4. all boundary vectors and diagonal orientation remain unchanged;
5. arithmetic is exact and overflow is detected or avoided by proof.

First-row reflection slicing is a further exact partition into orbits with
weights one or two. It is not needed for the row-transfer theorem.

## Arithmetic corollary

For the unweighted network every contraction coefficient is nonnegative and
the complete count is at most `N!`. Checked integer accumulation is exact when
it does not overflow. For CRT, if the deterministic pairwise-coprime modulus
product `M` satisfies `M > N!`, the nonnegative result in `[0,N!]` is uniquely
reconstructed from its residues. No floating-point threshold or rounding is
part of this argument.

## Executable evidence and failure modes

The repository's tests are intended as executable evidence for the definitions
and implementation mapping:

- B and C each have exactly 17 entries;
- empty and occupied local truth tables match the definitions;
- `v0...v1` enforces exactly one and `v0...v2` enforces at most one;
- the input index is mechanically equivalent to scanning C;
- compiled successors match sitewise-C successors for reachable parents;
- terminal last-k results match generic recursive C replay;
- small-N contractions match an implementation-independent oracle and known
  values.

The compiler must fail closed if a tensor entry, coefficient, virtual-leg
ordering, or required boundary differs. Count agreement alone does not prove
the premises of this theorem.

### Proposed trace certificate

For each certified small-N run, serialize every boundary layer in canonical
lexicographic `(columns,diag_dr,diag_dl,weight)` order and record:

- schema version, source revision, binary hash, compiler version, and arithmetic
  backend;
- canonical B-entry and C-entry SHA-256 hashes, boundary vectors, leg ordering,
  diagonal convention, and board mask;
- N, depth, support size, exact sum of weights, accepted transition count, and
  SHA-256 of the full canonical layer for literal-C, compiled-row, and optimized
  schedules;
- final exact count, independent-oracle count, overflow/CRT certificate, and
  verification result.

The equality gate compares the canonical layers themselves during the test;
the hashes make the result portable but are not a substitute for that exact
comparison. A mutation suite must independently flip one C coefficient, delete
one empty pass-through, permute one virtual leg, replace each boundary vector,
and reverse only one diagonal endpoint. Every mutation must either be rejected
by the compiler or produce a certificate mismatch before a known-count check is
consulted.
